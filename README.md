# 가을 맞이 단풍 메시지 달기

## GitHub Pages 업로드
저장소 최상위(root)에 `index.html`, `cover.png`, `form.png`, `complete.png`, `mascot.png`를 함께 올려 주세요. 별도의 assets 폴더는 필요하지 않습니다.

GitHub 저장소 Settings → Pages → Deploy from a branch → `main` → `/(root)`를 선택합니다.

## 동작
- 작성하기를 누르면 편지 작성 화면으로 이동합니다.
- 메시지(최대 300자), 행복기숙사명, 인스타그램 아이디를 입력해야 합니다.
- 개인정보 수집·이용 동의와 편지 소개 동의를 모두 체크해야 편지를 제출할 수 있습니다.
- 완료 화면에는 본인이 작성한 메시지만 표시됩니다.

## 운영 전 확인
현재는 브라우저 안에서 동작하는 프로토타입으로, 참가자 정보가 운영자에게 전송되거나 서버에 저장되지 않습니다. 실제 이벤트 운영 전에는 안전한 저장 기능과 개인정보 처리 고지·보관·파기 절차가 필요합니다.
